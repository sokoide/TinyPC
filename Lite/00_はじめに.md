# TinyPC Lite：はじめに

TinyPC Liteは、SeaBIOSがブートセクタを読み込み、ブートセクタが次のセクタを読み込んで実行するまでを、NASMとQEMUで確かめる短期コースである。既存TinyPCの要約ではなく、短期コース用の最小プログラムを独立してビルド・実行する。

## 60分の進め方

対象は、コマンドの実行とテキスト編集ができる人。x86アセンブリは未経験でよい。時間内に全命令を暗記する必要はない。

| 時間 | 講義・ハンズオン | 確認するもの |
| :--- | :--- | :--- |
| 0〜10分 | 起動の全体像と最小限のレジスタ・メモリの説明 | BIOS、Stage 1、Stage 2の役割 |
| 10〜30分 | 第1章：コードを保存、ビルド、起動、文字列を変更 | 512バイト、`55 aa`、自分の文字列 |
| 30〜50分 | 第2章：2段階ブートを作って起動 | 2行の表示とディスク・RAM配置 |
| 50〜55分 | 第2章：配置をずらす演習 | 予測と実際の違い |
| 55〜60分 | 第3章：自分の言葉で説明 | 読み込みとジャンプの区別 |

ツールのインストールとGUI起動確認は講義前に済ませる。60分は進行の目安で、受講者による所要時間は未計測。入力に時間がかかる場合は講師がコードを配布し、編集・実行・説明に時間を使う。

## この教材が扱うPC

QEMUが再現するx86 PCを、従来型BIOSであるSeaBIOSで起動する。CPUはリセット後にファームウェアの命令を実行し、SeaBIOSが機器を初期化して起動媒体を選び、ブートセクタへ制御を渡す。CPUが自分でディスク先頭を探しているわけではない。

現在のPCで使われるUEFIのネイティブ起動手順とは異なる。ここで学ぶのは、BIOS方式の「次のプログラムをメモリへ読み込み、実行を移す」という流れである。ホストPCがApple Siliconでも、QEMUのソフトウェアエミュレーションでx86の命令を実行できる。

## 到達目標

```text
CPU Reset (概要)
  → SeaBIOS
  → Boot Sector (0x7C00)
      ├─ INT 10h → "Booting..."
      └─ INT 13h → ディスクの次セクタを読む
                    → Stage 2 (0x8000)
                        └─ INT 10h → "Hello from Stage 2!"
```

この経路を自分で実装し、各段階の配置先と役割を説明できることが目標である。リセット直後からSeaBIOS内部の詳細、IVTの構造、デバイス制御の実装は本編へ残す。

## 環境と実行

講義前にNASM、QEMU（SeaBIOSを使える構成）、`make`、`dd`、`od`とGUI環境を用意する。次のコマンドが利用できることを確認する。

```sh
nasm -v
qemu-system-i386 --version
make --version
```

ハンズオンでは第1章で`~/tinypc-lite-work`を作り、第2章までそこで作業する。Vault内の配布実装を直接変更する必要はない。完成版を先に確認する場合は、TinyPCディレクトリから次を実行する。

```sh
cd impl/lite
make clean
make run
```

標準コマンドはGUI表示のQEMUである。INT 10hの出力はVGA画面に出るため、`-display none -serial stdio`では見えない。画面にBoot SectorとStage 2のメッセージが順に表示されたら成功。

```text
Booting...
Hello from Stage 2!
```

各章には作業用コードを掲載する。`impl/lite/`は比較・復旧用の完成版である。QEMUはウィンドウを閉じて終了する。表示後に止まるのは教材コードの意図した動作。
