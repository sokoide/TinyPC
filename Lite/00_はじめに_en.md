# TinyPC Lite: Introduction

TinyPC Lite is a short course that uses NASM and QEMU to follow the boot process from SeaBIOS loading a boot sector to that sector loading and running the next one. It is a standalone, minimal program for the short course, not a summary of the full TinyPC series.

## 60-minute schedule

This course is for learners who can run commands and edit text files. Prior x86 assembly experience is not required. The goal is not to memorize every instruction during the session.

| Time | Lecture and hands-on | What to check |
| :--- | :--- | :--- |
| 0–10 min | Overview of booting; essential registers and memory concepts | Roles of BIOS, Stage 1, and Stage 2 |
| 10–30 min | Chapter 1: save, build, and boot the code; change the message | 512-byte size, `55 aa` signature, custom message |
| 30–50 min | Chapter 2: build and boot a two-stage loader | Both messages and disk/RAM locations |
| 50–55 min | Chapter 2: change a disk location | Prediction compared with the result |
| 55–60 min | Chapter 3: explain the process in your own words | Difference between loading and jumping |

Install the tools and confirm that QEMU can open a graphical window before the session. Sixty minutes is a target schedule; learner completion time has not been measured. If typing takes too long, provide the code and spend the time editing, running, and explaining it.

## The PC this course covers

QEMU emulates an x86 PC booting with SeaBIOS, a traditional BIOS firmware. After reset, the CPU executes firmware instructions. SeaBIOS initializes devices, selects a boot device, and transfers control to its boot sector. The CPU does not search the disk for its own first sector.

This differs from the native UEFI boot process used by most current PCs. This course focuses on the BIOS-style sequence of loading the next program into memory and transferring control to it. Even on an Apple Silicon host, QEMU's software emulation can run x86 instructions.

## Learning objective

```text
CPU Reset (overview)
  → SeaBIOS
  → Boot Sector (0x7C00)
      ├─ INT 10h → "Booting..."
      └─ INT 13h → read the next disk sector
                    → Stage 2 (0x8000)
                        └─ INT 10h → "Hello from Stage 2!"
```

The objective is to implement this path and explain the role and location of each stage. Details of the reset sequence, SeaBIOS internals, IVT structure, and device control are covered in the full course.

## Environment and running the code

Before the session, install NASM, QEMU with SeaBIOS available, `make`, `dd`, and `od`, and ensure a graphical environment is available. Confirm these commands work:

```sh
nasm -v
qemu-system-i386 --version
make --version
```

For the hands-on, create `~/tinypc-lite-work` in Chapter 1 and use it through Chapter 2. You do not need to edit the distributed implementation in the Vault. To try the completed version first, run these commands from the TinyPC directory:

```sh
cd impl/lite
make clean
make run
```

The standard command opens QEMU in a graphical window. INT 10h output appears on the VGA display, so it is not visible with `-display none -serial stdio`. Success is indicated by these messages appearing in order:

```text
Booting...
Hello from Stage 2!
```

Each chapter includes the code to use in the hands-on. `impl/lite/` contains the completed version for comparison and recovery. Close the QEMU window to exit. The program intentionally stops after displaying its messages.
